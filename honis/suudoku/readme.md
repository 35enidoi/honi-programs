# これなに
数独を解くプログラムです  
SNSで見かけた数独が全く解けなくてイライラしたので作りました  
(作りましたと入ってるけどほぼCopilotのTabキー補完なのは内緒)
# どうやって使うの
1. banmen.txtに譜面を書く
2. python main.py
3. 解ける
# 気を付けること
私のpythonは3.13ですが、記法的には3.11までなら大丈夫なはずです。  
あと無限ループする可能性もあるので注意(そんなにちゃんとデバックしてないので...)  
英語も適当なので変かもしれない
# banmen.txtの記法
横方向をX軸、縦方向をY軸、値をValueとしたら  
```
Y X V
```
って感じ
XとYの順番に違和感あるけどまぁ許して

0始まりではなく1始まりなので注意  
例えば１列３行目を6とする場合  
```
1 3 6
```
って書けばおｋ
